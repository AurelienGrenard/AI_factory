## Dynamics

Let $W$ and $Z$ be Brownian motions with instantaneous correlation $\rho$.
For a Hurst exponent $H\in(0,1/2)$, define the Volterra Gaussian driver

```math
Y_t
=\sqrt{2H}\int_0^t(t-s)^{H-\frac12}\,\mathrm dW_s.
```

With constant forward variance $\xi_0>0$, the variance and risk-neutral spot
dynamics are

```math
v_t
=\xi_0\exp\!\left(
\eta Y_t-\frac{\eta^2}{2}t^{2H}
\right),
```

```math
\frac{\mathrm dS_t}{S_t}
=(r-q)\,\mathrm dt+\sqrt{v_t}\,\mathrm dZ_t,
\qquad
\mathrm d\langle Z,W\rangle_t=\rho\,\mathrm dt.
```

The non-Markovian convolution is simulated with the $\kappa=1$ hybrid scheme:
the singular current cell is sampled exactly and older cells use deterministic
power-kernel weights. The direct launcher evaluates the convolution in time;
the optional cuFFTDx launcher evaluates the same convolution in frequency
space.

| Symbol | Dataset field | Meaning |
|---:|---|---|
| $S_0$ | `spot` | Initial spot |
| $r$ | `risk_free_rate` | Risk-free rate |
| $q$ | `dividend_yield` | Dividend yield |
| $\xi_0$ | `xi_0` | Constant forward variance |
| $\eta$ | `eta` | Volterra volatility scale |
| $H$ | `hurst_exponent` | Hurst exponent |
| $\rho$ | `rho` | Brownian correlation |

The model follows [Bayer, Friz, and Gatheral (2016)](https://doi.org/10.1080/14697688.2015.1099717). The simulation follows the hybrid scheme of [Bennedsen, Lunde, and Pakkanen (2017)](https://arxiv.org/abs/1507.03004).

## Products

For every real number $z$, define $[z]^+=\max(z,0)$ and set
$\varepsilon=1$ for a call and $\varepsilon=-1$ for a put.

### European option

**Pricing method:** MC.

Parameters: strike $K$, maturity $T$, and side $\varepsilon$.

Let $\mathbb Q$ denote the risk-neutral measure. The payoff, value, and
estimator based on $M$ independent paths are

```math
H=[\varepsilon(S_T-K)]^+,
\qquad
V_0=\mathbb E^{\mathbb Q}\!\left[e^{-rT}H\right],
```

```math
\widehat V_0
=\frac{1}{M}\sum_{m=1}^{M}e^{-rT}H^{(m)},
```

where $H^{(m)}$ is the payoff generated by path $m$. Both the direct and
cuFFTDx launchers estimate the same quantity.

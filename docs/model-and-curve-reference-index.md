# Model and curve reference index

This page is the exhaustive index of mathematical references intentionally kept
next to model or curve source code. These local pages explain equations,
parameter meaning and numerical schemes. They are not owners of file trees,
public signatures, product availability or generated target lists: those
contracts belong to the source headers, the typed capability manifest and the
CUDA documents indexed by [`README.md`](README.md).
